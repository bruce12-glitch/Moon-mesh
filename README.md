# Moon Mesh

Moon Mesh is a children's coloring-book storefront featuring Miso the kitten. The site includes three illustrated book concepts, a free coloring activity, and a printable PDF.

## Run locally

From the repository root:

```sh
python3 -m http.server 8000
```

Visit [localhost:8000](http://localhost:8000/). The coloring studio reads a same-origin SVG, so use the local server to test it. The site uses plain HTML, CSS, and JavaScript and can be served by any static host.

## Book concepts

Midnight Kittens, Starlight Garden, and Pocket-Sized Planet are concept previews. The free coloring page is available now. The studio runs in the browser and does not collect personal data.

See [the design audit](docs/design-audit.md) for the Coco Wyo reference findings, the Moon Mesh palette, and the illustration inventory.
